## VOTS2026 Dataset
 
The VOTS2026 dataset is an updated version of the VOTS2023 and VOTS2024 dataset and is available through the VOT toolkit. The correct dataset will be automatically downloaded by selecting the corresponding experiment stack when configuring evaluation workspace. The following gallery gives an overview of the dataset.
